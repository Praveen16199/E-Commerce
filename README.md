# E-Commerce Fashion Store

This is a React-based e-commerce application for a fashion store.

## Prerequisites
- Node.js installed

## Setup & Installation
1.  Open the project folder in your terminal.
2.  Install dependencies:
    ```bash
    npm install
    ```

## How to Run
### Option 1: Using the Helper Script (Recommended for Windows)
Double-click **`start_dev.bat`** or run it in your terminal:
```powershell
.\start_dev.bat
```
*Note: This script automatically bypasses PowerShell execution policy restrictions.*

### Option 2: Using Command Prompt (cmd)
```cmd
npm run dev
```

### Option 3: Using PowerShell
If you see an error like `File ... npm.ps1 cannot be loaded because running scripts is disabled`, use this command:
```powershell
cmd /c "npm run dev"
```

## Features
- **User**: Browse products, Add to Cart, Checkout (COD), Login/Signup.
- **Admin**: Dashboard to Add/Edit/Delete products.
